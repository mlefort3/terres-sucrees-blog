## Montage

Pour le montage, voici les différents éléments :

1. Le fond de tarte
2. Dans le fond de tarte, le croustillant amande huile d'olive étalé
3. Par dessus le croustillant, une couche de gel fraise
4. Sur le dessus, la mousse vanille
5. Au milieu, des fraises fraîches coupées
6. Enfin, du basilic pour décorer

![](/images/img_8413-e1744922870489.jpg)

## Remarques

**Pâte sucrée** : plusieurs options sont possibles :

- Utiliser un substitut d’œuf pour une recette de pâte sucrée classique (pour ma part j'ai utilisé les produits et la [recette de Yumgo](https://yumgo.fr/blogs/recettes/pate-sucree))
- Utiliser une recette de pâte sucrée vegan, par exemple [celle-ci](https://www.marieclaire.fr/cuisine/la-pate-vegetale-sucree,1211684.asp) (que je n'ai pas essayée)
- Réaliser plutôt une pâte sablée, dans ce cas-là je vous conseille celle de [Planète Vegan](https://www.planetevegan.com/recettes/pate-sablee-vegan/)
